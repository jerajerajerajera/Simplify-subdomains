# Changelog

## 1.0.2

- Subdomains now sits in the Simplify group of Pelican's admin menu, together with the other Simplify add-ons,
  in the same order everywhere. This works with or without the Simplify core.

## 1.0.1

- The Simplify dashboard reads the subdomains of all server tiles in one go instead of once per server.

## 1.0.0

- First version as its own plugin: automatic subdomains in Cloudflare, settings in Advanced → Automatic subdomains
  and a Subdomain page per server.
- Takes over the settings and addresses of the subdomains built into PelicanSimplify.
- Shows the address on the server's tile when Simplify is installed.
